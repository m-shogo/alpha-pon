突き合わせて観測した**結果。EDINET を 2026-09-11 まで伸ばして TDnet の保存期間

## 【訂正】EDINET は「不祥事」の情報源ではない

PR #2063 のタイトルに「不祥事 Edge の45日待ちが消える」と書いたが、
**言い過ぎだった。**

観測された事由は子会社異動・主要株主異動・訴訟・代表者異動・資本政策で、
ユーザーが挙げた「サンリオの業務と関係ない不祥事」「バイトテロ」のような
**業績に無関係な不祥事は EDINET の臨時報告書には出てこない。**
それらは TDnet の適時開示（第三者委員会の設置、不正アクセス、お詫び）で出る。

### EDINET で**いま**測れるもの（価格のある期間を丸ごとカバー）

- **子会社の異動** — 3号 1,510件 / 8号の2 323件
  （ユーザーの挙げた「キオクシア系子会社」の系統）
- **訴訟** — 6号 45件
- 主要株主の異動 — 4号 1,281件
- 代表取締役の異動 — 9号 876件
- **訂正報告書** — 訂正有価証券報告書 1,689件 / 訂正内部統制報告書 200件
  （会計・内部統制の問題を示しうる。ただし体裁の訂正も多く、
  本文を読まないと材料性は分からない）

### TDnet を待つしかないもの

- 第三者委員会・特別調査委員会の設置
- 不正アクセス・情報流出
- 不適切会計の公表、お詫び・再発防止策

TDnet の保存は 2026-08-03 から。価格（84日遅延）が追いつくのは **2026-10-26**。

## 突き合わせのやり方（再現手順）

```bash
pnpm archive:edinet -- --from 2024-06-19 --to 2026-09-11 --execute
pnpm archive:tdnet  -- --from 2026-08-12 --to 2026-09-11 --execute
```

同じ (secCode, 日付) で、**事由コードが1つ・TDnet 見出しが1つ**の組だけを
使う。同日に複数あると対応が決まらない（決算短信が混ざって雑音になる）。

コードは5桁でそろえる。TDnet は4桁の `code` ではなく5桁の `sourceCode` を使う
（予備コードが 0 以外の銘柄が実測280件ある）。
