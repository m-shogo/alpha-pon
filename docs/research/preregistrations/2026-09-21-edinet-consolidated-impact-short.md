## 結果と判断（2026-09-21）

研究期間で1回測った。

| 項目 | 値 |
| --- | --- |
| シグナル → 約定 | 79 → 72（貸借でない6件を除外。売買代金不足459件・決算日71件は母集団の段階で除外） |
| Gross / Net 平均 | +144.4bps / **+69.3bps** |
| Net 中央値 | **+70.6bps** |
| 勝率 | 56.9% |
| クラスタ平均（反応日を等加重） | +65.9bps |
| クラスタ補正後 t | **1.12**（64 反応日） |
| 試行 / 閾値 | 2 / 2.38 → **FAIL**（研究期間の判定としても不合格） |

**上に書いた「封印を開ける条件」は3つとも満たした**（Net中央値 +70.6bps > 0 / クラスタ 64 ≥ 40 / 約定 72 ≥ 60）。

**それでも封印は開けない。** 理由:

- t = 1.12 は弱い。確認側の閾値（台帳の試行数で 2.38〜2.62、仮に 1.96 としても）に届く見込みが薄い
- 封印は **1 Edge 1回**。届かない見込みのまま開けると、その1回を捨てることになる
- 研究期間の標本はこれ以上増えない（期間の終わりは封印で固定）。
  つまり「もう少し待って研究期間で確かめ直す」という手は無い

**この事前登録の門の書き方が不備だった。** 「コストを引いて残るか」だけを見て
「効果の強さ」を見ていなかった。**儲かって見えることと、偶然でないことは別の条件**で、
封印を開ける門には後者が必要だった。次に同種の門を書くときは、強さ（t の下限）も先に決める。

いまの扱い: **この着想は保留**（封印は開けない・本番にも上げない）。
開けるとすれば、条件を変えずに標本を増やす手立てが見つかったときだけで、
