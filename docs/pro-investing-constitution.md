# alpha-pon 株Pro運用憲法

alpha-pon は買い推奨アプリではない。
目的は、長期投資・世界情勢・ニュース・一次情報・財務品質・イベント分析を組み合わせて、調査候補を出し、外れ方まで反省して賢くすること。

## 1. 絶対にやってはいけないこと

### 買い推奨にしない

- 「買い」「今すぐ買う」「必ず上がる」と書かない
- 出すのは「調査候補」「保留」「避ける」「証拠不足」
- 投資判断は人間が行う

### テーマ名だけで銘柄を選ばない

- AI関連だから上がる、宇宙関連だから上がる、半導体関連だから上がる、とはしない
- 売上・利益・受注・一次情報・需給に届くかを見る
- テーマは正しくても、銘柄が違う可能性を常に残す

### SNSや速報に引っ張られない

- SNSだけで判断しない
- 速報は誤報・煽り・過剰反応の可能性を持つ
- 公式情報、TDnet、EDINET、会社IR、Tier1報道を優先する

### 安いだけを押し目扱いしない

- 低品質企業の下落を「買い場」としない
- 赤字、希薄化、不祥事、下方修正、低流動性は別枠で扱う
- 良い会社と良い買い場は別物

### 学習結果で自動的にルール変更しない

- 件数不足でルールを消さない
- 相場局面だけの偶然を過信しない
- ルール変更は必ず人間レビューを挟む

## 2. 必ず見るべき株Proの常識

### 一次情報

- TDnet
- EDINET
- 会社IR
- 決算短信
- 決算説明資料
- 自社株買い、増資、下方修正、不祥事、M&A、TOB、配当修正

一次情報が missing の材料は、仮説扱いにする。

### 財務品質

- ROIC
- ROE
- FCF
- FCFマージン
- 営業利益率
- 自己資本比率
- ネットキャッシュ
- 売上・利益の継続性
- 競争優位

長期投資の候補は、テーマより先に財務品質を見る。

### バリュエーション・過熱

- 高値からの下落率
- 60日上昇率
- TOPIX比
- 出来高急増
- PER/PBR過去レンジは将来拡張

良い会社でも高すぎれば保留。
悪い会社が下げているだけなら避ける。

### 需給

- IPO後の売り圧
- ロックアップ
- 出来高急増
- 公募売出し
- 新株予約権
- MSワラント
- 流動性不足

材料が良くても、需給が悪ければ上がらない。

## 3. 深い考察の必須セット

銘柄やテーマを考えるときは、毎回以下を出す。

1. 上がる仮説
2. 上がらない仮説
3. 下がる仮説
4. もう織り込み済みの可能性
5. 親会社・子会社・関連会社・競合の方が本命の可能性
6. 一次情報で確認すべきこと
7. 財務・バリュエーション・需給で危ない点
8. 外れた場合に保存する理由DB
9. 次に見る銘柄群
10. 判定は「調査候補 / 保留 / 避ける / 証拠不足」

## 4. 一番大事な考え方

上がった理由より、上がらなかった理由を残す。

テーマは正しかったのに、銘柄が違ったのか。
銘柄は良かったのに、タイミングが悪かったのか。
利益に届かなかったのか。
もう織り込み済みだったのか。
一次情報が弱かったのか。
需給が悪かったのか。

この外れ方を分類してDBに残すことが、alpha-ponの学習の中心。

## 5. 最終判断ラベル

### 調査候補

材料はあるが買い推奨ではない。一次情報・財務・過熱・反証条件を確認する。

### 保留

テーマや材料はあるが、証拠・価格・財務・需給のどこかが不足している。

### 避ける

増資、下方修正、不祥事、低品質、過熱、流動性不足などが強い。

### 証拠不足

ニュースや仮説はあるが、一次情報で確認できない。

## 6. 運用ルール

- 迷ったら保留
- 強いテーマほど反証を強く見る
- 急騰銘柄はまず過熱を見る
- 下落銘柄はまず品質悪化を見る
- 上がらなかった理由を必ず保存する
- 1社に拘らず、親会社・関連会社・競合・部品会社まで見る
- 毎朝の提案は、買い判断ではなく調査キューとして扱う
