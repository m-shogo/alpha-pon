# 企業固有ショック / 不祥事ディップ 過去事例ケースブック

> 研究用。買い推奨ではありません。score は「事件そのものが企業価値を恒久的に壊しにくく、下落後に調査しやすいか」の 20 点評価です。高得点 = 必ず上がる、ではありません。
>
> 詳細データ・出典は `data/idiosyncratic_shock_cases.yml`、評価定義は `docs/idiosyncratic-shock-playbook.md` を正本とします。

## まず見る境界

- **16–20点**: research_priority。個人切除型など。価格が落ち着いた後の強い調査候補。
- **12–15点**: watch。類似事例・一次情報・業績を追加確認。
- **8–11点**: caution。ブランド/規制/キーパーソン問題が重い。
- **0–7点**: avoid。組織不正・粉飾など。「大きく下げた」を買い理由にしない。

12点以上でも、`confirmed evidence`、`非マクロ主因`、`stabilized_after_drop`、`accountingIntegrity > 0` を満たさなければ通知しません。

## 類似型の見取り図

### A: 個人切除型 — 高得点になりやすい

McDonald's / TI / Lockheed / Priceline / Intel。

共通点:

- 財務報告に影響なし
- 事件の行為者が限定される
- 後継経営者がいる
- 商品・顧客需要・供給網が止まらない
- 規制免許に直結しない

この型でも**急落初日は買い判定しない**。価格ゲートは独立。

### B: キーパーソン型 — 点数を下げる

Wynn / HP / Papa John's / KADOKAWA / 日産。

「本人を辞めさせれば終わる」ように見えても、創業者ブランド・戦略・提携・免許が人物に依存している。

### C: バイトテロ / 顧客迷惑動画 — 今回正式に対象化

バーミヤン / 東急レクリエーション / Domino's / セブン-イレブン / スシロー / くら寿司。

ここでは以下を確認する。

1. 行為者が従業員か顧客か
2. 商品が実際に顧客へ提供されたか
3. 1店舗か複数店舗か
4. 衛生問題が本業へ直接波及したか
5. FC/本部の教育・管理不全へ広がったか
6. 来店客数・既存店売上が落ちたか

「客へ提供されていない + 1店舗 + 行為者処分 + 全社業績無傷」なら個人切除型に近づく。

### D: 組織ガバナンス型 — すぐ買わない

Activision / フジ / Uberなど。

当初1人の問題に見えても、第三者委員会や複数証言で会社文化・経営陣へ広がる場合がある。

### E: 粉飾・組織不正 — 原則ブロック

Olympus / Toshiba / Wells Fargo / Suruga Bank / Luckin / Volkswagen。

下落率が50%でも `accountingIntegrity=0` なら12点通知のハードゲートを通さない。
