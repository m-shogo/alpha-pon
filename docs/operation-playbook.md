# alpha-pon 運用プレイブック

目的: 株Proアプリとして、毎朝・重要判断時・新規銘柄追加時に迷わず使える運用手順を固定する。

> 注意: 本ドキュメントは買い推奨ではなく、調査・反証・保留・改善のための運用手順です。

## 1. 基本姿勢

alpha-pon は「上がる銘柄をそれっぽく言うアプリ」ではない。

目標は次の4つ。

1. 見落としを減らす
2. 良い会社と良いタイミングを分ける
3. 上がらない理由・下がる理由を先に出す
4. 外れた理由を蓄積して次の精度を上げる

## 2. 毎朝見る順番

毎朝は、細かいレポートを全部読む前に、まず司令塔を見る。

### まず見る

1. `reports/strategic_advice_latest.md`
2. `reports/pipeline_health_summary_latest.md`
3. `reports/pro_knowledge_refresh_latest.md`
4. `reports/stock_pro_committee_latest.md`
5. `reports/stock_pro_summary_latest.md`

### 必要に応じて見る

6. `reports/company_onboarding_audit_latest.md`
7. `reports/stock_pro_quality_audit_latest.md`
8. `reports/stock_pro_improvement_roadmap_latest.md`
9. `reports/company_network_latest.md`
10. `reports/company_coverage_audit_latest.md`
11. `reports/regime_hypothesis_alignment_latest.md`
12. `reports/stale_hypotheses_latest.md`

## 3. 完全版dailyの実行

通常の完全版:

```bash
bash scripts/run-daily-complete.sh
```

Pro知識ブラッシュアップ込み:

```bash
bash scripts/run-daily-complete-with-refresh.sh
```

政治・戦争・AI・宇宙/Starlink・気候・食糧・金利など、前提が変わりやすい時期は `with-refresh` を使う。

## 4. 大事な判断では必ずPro会議を通す

次の場合は、必ず `stock_pro_committee_latest.md` を見る。

- 新規銘柄を追加するとき
- 保留/証拠不足から調査候補へ上げるとき
- 決算・株主総会・配当・中計・自社株買いなど重要IRイベント前後
- 通知候補にする/重要度を上げるとき
- 社会情勢・テーマ認識を変えるとき

判断は単独でしない。

必ず次を見る。

- 合意点
- 対立点
- 足りない情報
- 上がらない理由
- 下がる理由
- 次に集める情報
- 最終ラベル

## 5. 新規銘柄を聞かれた時の流れ

知らない銘柄や追っていない銘柄は、いきなり結論を出さない。

### coverage の段階

- `unknown`: 未調査。一般論・確認項目だけ。
- `provisional`: 仮登録。仮説・反証・不足情報は出せる。
- `covered`: 考察可能。ただし買い判断ではない。

### 必須チェック

1. 銘柄コード・社名・上場市場
2. 公式IRページ
3. 決算日・直近決算資料
4. 株主総会・招集通知・議案
5. 配当・自社株買い・株主還元
6. 事業セグメント
7. 財務品質: ROIC / FCF / 利益率 / 自己資本比率
8. バリュエーション: PER / PBR / 過去レンジ / 同業比較
9. 競合・親会社・子会社・関連会社
10. 社会情勢との接続
11. 上がらない理由
12. 下がる理由

これが埋まるまで、強い結論は出さない。

## 6. サンリオのような個別銘柄を聞かれた時

例: `8136 サンリオ`

最初に見る順番:

1. 直近IRイベント
   - 決算
   - 株主総会
   - 招集通知
   - 議案
   - 配当
   - 資本政策
2. 社会情勢
   - 円安/円高
   - インバウンド
   - 海外消費
   - 金利
   - 中国/アジア/北米需要
3. 会社の良いところ
   - IP
   - ライセンス
   - 海外展開
   - 利益率
4. 上がらない理由
   - 織り込み済み
   - 期待が高すぎる
   - 良い決算でも市場期待未満
   - 他のIP銘柄へ資金が流れる
5. 下がる理由
   - 海外成長鈍化
   - 利益率悪化
   - 高PER調整
   - 総会/決算後の材料出尽くし
6. 競合・関連会社
   - 任天堂
   - バンダイナムコ
   - オリエンタルランド
   - タカラトミー
7. ラベル
   - 調査候補
   - 保留
   - 証拠不足
   - 避ける
   - 追わない/保留

## 7. ラベルの意味

- `調査候補`: 証拠はあるが、買い判断ではない。
- `保留`: テーマはあるが、価格・証拠・財務・需給のどれかが足りない。
- `証拠不足`: 一次情報や価格データが足りない。
- `避ける`: 低品質・希薄化・不祥事・過熱・流動性不足が強い。
- `追わない/保留`: テーマはあるが、今は注意資源を使う価値が低い。

## 8. 精度を上げるための優先順位

銘柄を増やすより、1銘柄あたりの解像度を上げる。

優先順:

1. 直近IRイベント
2. 決算・総会・配当・資本政策
3. バリュエーション過去レンジ
4. 財務品質
5. 会社ネットワーク
6. 社会情勢との接続
7. 上がらない理由
8. 下がる理由
9. 外れ理由の蓄積

## 9. Pro知識のブラッシュアップ

Proエージェントの知識は固定しない。

定期的に見る領域:

- 政治・政策・規制
- 戦争・地政学・安全保障
- AI・データセンター・半導体・電力
- 宇宙・衛星通信・Starlink周辺
- 気候・食糧・災害
- 金利・為替・インフレ・景気

情勢が変わったら、銘柄仮説より先に `current-regime.yml` と Proエージェントの前提を見直す。

## 10. やってはいけないこと

- ニュースやSNSだけで強い判断を出す
- 総会・決算・配当を見ずに個別銘柄を語る
- 良い会社と良い投資タイミングを混同する
- 上がらない理由を書かずに調査候補へ上げる
- 下がる理由を書かずに強気にする
- 古い仮説を残し続ける
- 外れた理由を記録しない

## 11. 中学生でも分かる説明

このアプリは「この株が上がるよ」と当てずっぽうで言うものではない。

毎回こう考える。

- 次の発表はいつ？
- 決算はどう？
- 株主総会で何を話す？
- 配当はどう？
- 会社はちゃんと儲かってる？
- 今の株価は高すぎない？
- ライバルは誰？
- 人気なのに上がらない理由は？
- 間違ったら何で下がる？

これを見てから、調査するか、保留するか、追わないかを決める。
