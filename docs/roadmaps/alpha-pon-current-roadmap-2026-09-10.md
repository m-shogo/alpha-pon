## 0-B. 【重大な訂正】J-Quants はブロックされていなかった（2026-09-11）

このロードマップの 2026-09-10 版は「**J-Quants の認証が切れており、これが唯一の
ブロッカー。人間がキーを再発行する必要がある**」と書いていた。**これは誤りだった。**

### 誤診の中身

存在しないパス `/v2/listed/info` を叩いて generic な HTTP 403 を受け、
「キーが無効」と結論していた。実際に叩くべきだったのは
`/v2/equities/bars/daily` で、こちらは **HTTP 200 で実データを返す**。

```
GET /v2/equities/bars/daily?code=13060&from=20250901&to=20250930
→ 200 / 20本 / 0.1秒
```

契約範囲 **2024-06-19 〜 2026-06-19**（Free の2年窓・84日遅延と一致）。
**人間の作業は最初から不要だった。**

同じ誤診を繰り返さないため、切り分け専用の診断コマンドを入れた（#2041）。
鍵の値は一切出力しない。

```bash
pnpm diagnose:jquants -- --execute
```

### 真の制約 1: バースト枠

```
間隔 10s : [200,200,200,200,200,429]
間隔  5s : [200,200,200,200,429,429]
間隔  3s : [200,200,200,200,429,429]
```

**間隔を空けても4〜5回で枯渇する。レートではなくバースト枠。**
一度 429 になると 60秒台まで回復せず、`Retry-After` ヘッダは返らない。
従来の「3秒固定＋線形10秒バックオフ」では1リクエスト最悪100秒かかり、
これが「全銘柄 timeout 15000ms（563回）」の正体だった。

適応型レート制限を入れて解消（#2041）。実測で10銘柄10/10成功・142秒。

### 真の制約 2: 84日遅延（これは本物で、消えない）

`toBacktestPriceSeries` は `executable` 境界を使うので、
`retrievedAt` / `firstExecutableAt` が `asOf` を超える行は選ばれない。

**帰結: J-Quants Free の価格でリアルタイム売買はできない。**
検証（過去の計測）には何の支障もない。**執行には別系統の気配値が要る。**
これは項目22（リアルタイム価格源）と同じ話であり、有料化の第一候補。

### 副産物: PIT ユニバース問題も同時に解けた

`/v2/listed/info` `/v2/equities/info` `/v2/equities/listed` はいずれも
「そんなエンドポイントは無い」と 403 を返す。銘柄一覧が取れない、が
09-10 時点の理解だった。

だが `/v2/equities/bars/daily?date=YYYYMMDD` が **1リクエストで全4,410銘柄**
を返す。そして **その日に板が立った銘柄の集合こそ、その日のユニバース**。
別エンドポイントは要らなかった。上場・廃止・新規のタイミングも自動的に
正しくなるので、**生存バイアスが構造的に入らない**。

取り込み CLI を入れた（#2042）。1営業日=1リクエスト、520営業日で520回。

```bash
pnpm ingest:prices -- --from 2024-06-19 --to 2026-06-19 --execute
```

1日 4,410件・3.3MB。2年で約 1.4GB（gitignore 済み・0700/0600）。
中断安全・再開可能。実測 45分〜4時間。

### この誤診から取るべき教訓

**エンドポイントが 403 を返したとき、「認証が悪い」と「そのパスが無い」を
区別せずに結論を出した。** 1本しか叩いていないのに「唯一のブロッカー」と
断定し、人間に作業を振った。複数のエンドポイントで切り分けるまで
原因を確定させない。診断コマンドはそのための道具として常設した。

---

rate limit 既定 3000ms/req（500銘柄の全履歴で約25分）。

**帰結**

1. **J-Quants Free では実売買も紙トレードもできない。** 84日遅延。**検証専用**
2. benchmark は 1306 ETF 代用。信託報酬分の乖離を計測して記録する
3. backtest 期間は最大2年
4. TDnet public viewer は**約1ヶ月しか遡れない**（実測: 2026-06-10 / 2025-09-10 とも
   `first page not found`。2026-09-09 は127件取得可）
