## 3. 実データで出た最初の数字

### generic reversal（ラベル不要の基準線）

個別要因で -10% 下げた翌営業日の始値で買い、5営業日持つ。
流動性5億円/日以上、市場モデルで異常収益を測る、権利落ち日は除外。

```
  Gross Alpha 平均: -29.6bps
  Net   Alpha 平均: -66.7bps / 中央値 -69.6bps
  勝率: 39.6%
  t = -0.57 (クラスタ補正後 / 65イベント日) ← 判定に使う値
  t = -1.71 (未補正 / 685件)               ← 同日の相関を無視した参考値
  False Discovery Guard: FAIL
```

**コスト前ですでに負けており、コストで37bps さらに削られる。**
統計的に有意ではない（t = -0.57）が、点推定は負。

**「急落したから買う」は成立しない。** 不祥事・子会社などの Edge は、
この基準線を超えて初めて意味を持つ。

クラスタ補正で t が3倍違う（-1.71 → -0.57）。同じ日に大量のシグナルが
出るため、685件を独立と数えると有意に見える。実質は65イベント日。

**注意: 取り込み途中の値**（503営業日中247日）。市場モデルの推定窓(120本)が
埋まるのが末尾だけなので確定値ではない。全期間の取り込み後に測り直す。

## 4. 実データを流して分かった測定上の落とし穴

合成データでは全部通っていた。**3つとも候補件数を見ても気づけない型。**
詳細は前版の 0-C。

| # | 落とし穴 | 効き方 |
| --- | --- | --- |
| 1 | 株式分割を暴落として検出 | 189営業日で -25%以下が470件、大半が分割 |
| 2 | 非流動銘柄が候補を埋め尽くす | 4,321銘柄 1,775件 → 流動830銘柄 432件 |
| 3 | ETF ベンチマークが β を一様に希薄化 | 平均β 0.59 → ユニバース等加重で 1.00 |

**順序が要る。** 2と3を先に潰さないと、市場モデルを入れるほど候補が増える
（553件 → 1824件）。

### 自分を騙しかけた記録

ユニバース指数に替えたら暴落日の候補が 0 件になった、と一度結論しかけた。
確認すると **809銘柄すべてで β が推定できていなかっただけ**だった。

**「候補が減った」は成果ではない。** 減った理由が「説明がついた」なのか
「測れなかった」なのかを必ず分ける。CLI は `market_model_unavailable` の
件数と横断βの平均を常に出し、平均βが 1 から 0.25 以上離れたら警告する。

## 5. 不祥事 Edge はいつ測れるか

### ラベル源は TDnet で確保できた

daily は毎朝 TDnet を取得していたが、キーワード抽出に使って**捨てていた**。
公開閲覧サービスは約1ヶ月しか遡れない（実測: 2026-08-03 は取れるが
2026-07-31 は not found）。**保存しなかった日は永久に失われる。**

2026-09-11 に残っていた 2026-08-03〜09-11 の **10,508件 / 3,703社** を回収し、
以後は毎朝追記する。欠落は回収期限つきで検出する。

### 29営業日での当たり方

```
  earnings                  3387件 / 2907社
  equity_offering            277件 /  143社
  corporate_action           145件 /  108社
  misconduct                  34件 /   25社 ← 研究対象
  subsidiary_localized        24件 /   24社 ← 研究対象
  regulatory_or_litigation    20件 /   17社
```

研究対象は**月58件、年間約700件**。イベントスタディに足りる。

### まだ測れない理由

```
  価格の上限（84日遅延）  2026-06-19
  開示の保存開始          2026-08-03
  重なり始める            2026-10-26（あと45日）
```

**それまで不祥事 Edge の検証はできない。** 日が経つほど標本が増える。

## 6. 消えない制約: 84日遅延

`toBacktestPriceSeries` は `executable` 境界を使うので、
`retrievedAt` / `firstExecutableAt` が `asOf` を超える行は選ばれない。

**J-Quants Free の価格でリアルタイム売買はできない。**
検証（過去の計測）には何の支障もないが、⑥監視 と ⑦通知 を
「今日の該当銘柄」として動かすには**別系統の気配値が要る**。

これは有料化の第一候補。ただし **Edge が確認できるまで課金する理由が無い**。
順序は「検証 → Edge 確認 → 気配値を買う → 執行」。

## 8. 維持する原則

- 未確定日時を捏造しない
- 原因を名乗れないときは名乗らない（`unknown` で残す）
- SNS・掲示板を signal source にしない

- 自動でルールを削除しない（提案のみ）
- holdout を早期に開けない
- **「候補が減った」を成果と読まない。減った理由を必ず分ける**
- **取得したものはまず保存してから使う**（保持期間の短いソースは特に）
