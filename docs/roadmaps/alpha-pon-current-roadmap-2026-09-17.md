## 4. 2026-09-17 に直した測定の欠陥

どれも**単体テストは通っていた**。実データの件数、無作為エントリー、
1件の手検算で見つけた。

| # | 欠陥 | 大きさ | PR |
| --- | --- | --- | --- |
| 12 | 上場廃止した銘柄がマスタから消える | ETF 6銘柄を判定できず、125銘柄の業種が不明 | #2118 |
| 13 | 直したあと一部の測定だけ測り直した | 伝播は反応日修正の前の数字のままだった | #2119 |
| 14 | 保有中の株式分割で損益が -50% | 急落買いの2件が -64% / -49%。平均を 45bps 押し下げ | #2120 |
| 15 | 指数を引けから、銘柄を寄付から測っていた | 現行 − 正しい値が1件平均 -7〜+16bps、最大 273bps | #2120 |
| 16 | 予想の減額を「直前の開示」と比べていた | 1Q が常に基準なし・別の年度と比較 | #2122 |
| 17 | 来期の期末日の項目名が違った（`NxtFYEn`） | 1Q の基準 161 → 1,428件 | #2123 |
| 18 | **期間の最後の流動性で母集団を選んでいた** | **無作為に買うだけで 5日 +17bps / 20日 +53bps**。EDINET の D+60 は +222 → -174bps | #2125 |

**18 の教訓**: 母集団を「期間全体を見て」選ぶと、選び方そのものが結果を作る。
条件は必ず**その時点で分かっていた情報**で判定する。そして
**無作為エントリーの超過（零点）を測って 0 付近か確かめる**まで、測定を信用しない。

**13 の対策**: 前提を変える修正を入れたら、台帳の全測定を測り直す。
表の数字は台帳の最新値から写し、記録時刻が最後の修正より後かを確かめる。

## 5. 次にやること

### 決めたこと（2026-09-17）

1. **急落の「売り」を同じ Edge の別条件として扱う。** 買いの結果を見てから向きを
   決めるので、試行は通算で数える（次は6回目、閾値はさらに上がる）
2. **売れるかどうかの制約を先に入れてから測る。**
   - 貸借銘柄だけ（銘柄マスタの `Mrgn`。2025-06-30 の行で `"Mrgn":"2","MrgnNm":"貸借"` を確認）
   - 空売り価格規制: 基準値段から10%以上下げた時点から**翌日の立会終了まで**、
     下落局面では直近公表価格以下の空売りが禁止される。ただし
     **個人投資家の信用取引による50売買単位以下の空売りは適用除外**
     （[JPX 空売り規制](https://www.jpx.co.jp/equities/trading/regulations/02.html) の検索結果の要約で確認。
     一次資料のページと FAQ は自動取得できなかった（403）ので、**売買の前に人が確認する**）。
     想定元本100万円なら株価200円以上で50単位以下に収まるので、
     **翌営業日の寄付のまま、50単位以下の取引に限る**
   - 貸株料・逆日歩の見積りを入れる
3. **確認は封印期間で1回だけ。** 急落の仮説は 2025-07〜2026-02 をすでに見ているので、
   使えるのは 2026-03-01 以降。確認期間は **2026-03-01 以降の 189 営業日**
   （取り込まれた営業日の数。価格を見ずに決まる）。**貸借で絞った売り**は研究期間で
   252営業日に80クラスタなので、189 営業日で約60クラスタになる見積り。
   データは 2026-11 末〜12 月上旬まで要り、84日遅延のため
   **取得できるのは 2027-02〜03 頃**（祝日を除いた概算）。
   当初は「クラスタ60以上」としていたが、数えるには封印の価格を見る必要があるので改めた（#2130）。
   研究期間の効果の大きさ（1クラスタあたり t/√n = 0.34）がそのまま続くなら、
   60クラスタで期待 t ≈ 2.6。研究期間の値は選ばれた分だけ大きめに出るので、実際はそれ以下と見る。
   開封は `pnpm research:holdout:open`（#2130）。引数だけなら計画の表示、`--execute` で1回だけ実行する。
   2026-09-17 時点で 2026-03-01 以降の取り込み済み営業日は 78 / 189

## 7. 維持する原則

- 結果を見る前に条件を決める（事前登録）。見たら試行として数える
- 修正で測り直すときも、データが変われば新しい試行として数える
- 条件はその時点で分かっていた情報で判定する
- 零点（無作為エントリー）を測ってから結果を読む
- 候補を1件、生データから手で検算してから結論を出す
- 封印は開けない。開けるなら1 Edge 1回、記録を残す
- 未確定日時を捏造しない / 原因を名乗れないときは名乗らない
- SNS・掲示板を signal source にしない
